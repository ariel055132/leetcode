## Q70. Climbing Stairs

[LeetCode 題目](https://leetcode.com/problems/climbing-stairs/)

- **題意**：每次走 1 或 2 階，求走到第 n 階的方法數。
- **解法**：最後一步來自 n-1 或 n-2，因此 ways[n]=ways[n-1]+ways[n-2]；只需保留前兩項。
- **範例**：n=3：由前兩階的方法數 1 與 2 相加，得到 3。
- **複雜度**：時間 O(n)，額外空間 O(1)。
- **注意**：令空路徑 ways[0]=1；本題 n>=1。

```java
class Solution {
    public int climbStairs(int n) {
        int twoBack = 1, oneBack = 1;
        for (int step = 2; step <= n; step++) {
            int current = oneBack + twoBack;
            twoBack = oneBack;
            oneBack = current;
        }
        return oneBack;
    }
}
```

## Q322. Coin Change

[LeetCode 題目](https://leetcode.com/problems/coin-change/)

- **題意**：硬幣可重複使用，求湊成 amount 的最少硬幣數；無法湊成回傳 -1。
- **解法**：dp[sum] 是湊成 sum 的最少數量；枚舉最後一枚 coin，取 dp[sum-coin]+1 的最小值。
- **範例**：coins=[1,2,5]、amount=11：最後取 5，接上金額 6 的兩枚，得到 3 枚。
- **複雜度**：時間 O(amount×硬幣種類數)，空間 O(amount)。
- **注意**：dp[0]=0；不可達狀態用 amount+1，不用 Integer.MAX_VALUE 再加 1。

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);
        dp[0] = 0;
        for (int sum = 1; sum <= amount; sum++) {
            for (int coin : coins) {
                if (coin <= sum) dp[sum] = Math.min(dp[sum], dp[sum - coin] + 1);
            }
        }
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

## Q300. Longest Increasing Subsequence

[LeetCode 題目](https://leetcode.com/problems/longest-increasing-subsequence/)

- **題意**：求最長嚴格遞增子序列長度，不要求元素連續。
- **解法**：tails[len-1] 保存長度 len 的遞增序列可達到的最小尾值。二分找第一個 >=x 的位置替換；較小尾值更容易延伸。
- **範例**：[10,9,2,5,3,7,101,18]：tails 最終為 [2,3,7,18]，長度 4。
- **複雜度**：時間 O(n log n)，額外空間 O(n)。
- **注意**：tails 不一定是原陣列中的同一條實際子序列；本題只要求長度。

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int[] tails = new int[nums.length];
        int size = 0;
        for (int x : nums) {
            int left = 0, right = size;
            while (left < right) {
                int mid = left + (right - left) / 2;
                if (tails[mid] < x) left = mid + 1;
                else right = mid;
            }
            tails[left] = x;
            if (left == size) size++;
        }
        return size;
    }
}
```

## Q1143. Longest Common Subsequence

[LeetCode 題目](https://leetcode.com/problems/longest-common-subsequence/)

- **題意**：求兩個字串共同子序列的最長長度。
- **解法**：字元相同則用左上角+1；不同則取上方或左方最大值。壓成一列時，額外保存尚未覆寫的左上角。
- **範例**：abcde 與 ace：依序配對 a、c、e，答案 3。
- **複雜度**：時間 O(mn)，額外空間 O(n)，n 為 text2 長度。
- **注意**：子序列可以跳過字元，與共同連續子字串不同。

```java
class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int[] dp = new int[text2.length() + 1];
        for (int i = 1; i <= text1.length(); i++) {
            int diagonal = 0;
            for (int j = 1; j <= text2.length(); j++) {
                int oldAbove = dp[j];
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) dp[j] = diagonal + 1;
                else dp[j] = Math.max(dp[j], dp[j - 1]);
                diagonal = oldAbove;
            }
        }
        return dp[text2.length()];
    }
}
```

## Q139. Word Break

[LeetCode 題目](https://leetcode.com/problems/word-break/)

- **題意**：字典中的單字可重複使用，判斷能否完整切分 s。
- **解法**：dp[i] 表示前 i 個字元能切分。從可達位置比對每個單字，匹配就把單字後方的位置設為可達。
- **範例**：leetcode、[leet,code]：dp[0] → dp[4] → dp[8]，回傳 true。
- **複雜度**：時間 O(nDL)，D 為字典大小、L 為最長單字長度；空間 O(n)。
- **注意**：startsWith(word,i) 避免反覆建立 substring；只允許完整覆蓋，不可跳過字元。

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;
        for (int i = 0; i < s.length(); i++) {
            if (!dp[i]) continue;
            for (String word : wordDict) {
                int end = i + word.length();
                if (end <= s.length() && s.startsWith(word, i)) dp[end] = true;
            }
        }
        return dp[s.length()];
    }
}
```

## Q377. Combination Sum IV

[LeetCode 題目](https://leetcode.com/problems/combination-sum-iv/)

- **題意**：使用不同正整數 nums，計算總和為 target 的有序序列數；順序不同算不同方法。
- **解法**：以最後一個數為分類，dp[sum]=Σdp[sum-x]；外層枚舉 sum，內層枚舉 x，保留不同排列。
- **範例**：nums=[1,2,3]、target=4：dp[0..4]=[1,1,2,4,7]，答案 7。
- **複雜度**：時間 O(target×n)，額外空間 O(target)。
- **注意**：原始 Blind 貼文的 Combination Sum 連結指向本題。以 long 加總並封頂 int 最大值，避免無法延伸到目標的中間狀態溢位；題目保證最終答案在 int 範圍內。

```java
class Solution {
    public int combinationSum4(int[] nums, int target) {
        long[] dp = new long[target + 1];
        dp[0] = 1;
        for (int sum = 1; sum <= target; sum++) {
            for (int x : nums) {
                if (x <= sum) {
                    dp[sum] = Math.min(Integer.MAX_VALUE, dp[sum] + dp[sum - x]);
                }
            }
        }
        return (int) dp[target];
    }
}
```

## Q198. House Robber

[LeetCode 題目](https://leetcode.com/problems/house-robber/)

- **題意**：不能偷相鄰房子，求最多可取得的金額。
- **解法**：處理目前房子時，只能選「不偷：前一間最佳值」或「偷：前兩間最佳值+目前金額」。
- **範例**：[2,7,9,3,1]：每個前綴最佳值為 2、7、11、11、12。
- **複雜度**：時間 O(n)，額外空間 O(1)。
- **注意**：更新之前保留前兩個狀態，不能先覆寫再用。

```java
class Solution {
    public int rob(int[] nums) {
        int twoBack = 0, oneBack = 0;
        for (int money : nums) {
            int current = Math.max(oneBack, twoBack + money);
            twoBack = oneBack;
            oneBack = current;
        }
        return oneBack;
    }
}
```

## Q213. House Robber II

[LeetCode 題目](https://leetcode.com/problems/house-robber-ii/)

- **題意**：房子排列成環，首尾也相鄰，求最大偷取金額。
- **解法**：合法答案不可能同時包含首尾；分別求排除最後一間與排除第一間的線性版本，再取最大值。
- **範例**：[2,3,2]：比較 [2,3] 與 [3,2]，兩者最佳值皆為 3。
- **複雜度**：時間 O(n)，額外空間 O(1)。
- **注意**：只有一間時直接回傳，避免兩個排除版本都變成空區間。

```java
class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) return nums[0];
        return Math.max(range(nums, 0, nums.length - 2), range(nums, 1, nums.length - 1));
    }
    private int range(int[] nums, int left, int right) {
        int twoBack = 0, oneBack = 0;
        for (int i = left; i <= right; i++) {
            int current = Math.max(oneBack, twoBack + nums[i]);
            twoBack = oneBack;
            oneBack = current;
        }
        return oneBack;
    }
}
```

## Q91. Decode Ways

[LeetCode 題目](https://leetcode.com/problems/decode-ways/)

- **題意**：1..26 對應 A..Z，求數字字串的合法解碼數。
- **解法**：最後一碼為 1..9 時可接前一個前綴；最後兩碼在 10..26 時可接前兩個前綴。兩類切分互不重疊。
- **範例**：226：前綴 2、22、226 分別有 1、2、3 種；06 則為 0。
- **複雜度**：時間 O(n)，額外空間 O(1)。
- **注意**：0 不可獨立解碼。與 Q377 相同，中間數量以 int 最大值封頂，最終答案依題目保證仍精確。

```java
class Solution {
    public int numDecodings(String s) {
        if (s.isEmpty()) return 0;
        long twoBack = 1, oneBack = s.charAt(0) == '0' ? 0 : 1;
        for (int i = 1; i < s.length(); i++) {
            long current = s.charAt(i) == '0' ? 0 : oneBack;
            int pair = (s.charAt(i - 1) - '0') * 10 + s.charAt(i) - '0';
            if (pair >= 10 && pair <= 26) current += twoBack;
            twoBack = oneBack;
            oneBack = Math.min(Integer.MAX_VALUE, current);
        }
        return (int) oneBack;
    }
}
```

## Q62. Unique Paths

[LeetCode 題目](https://leetcode.com/problems/unique-paths/)

- **題意**：從 m×n 網格左上到右下，每次只能向右或向下，求路徑數。
- **解法**：每格的方法數等於上方與左方的總和；一列 dp 中的舊值是上方，已更新的前一格是左方。
- **範例**：m=3、n=2：各列狀態為 [1,1]、[1,2]、[1,3]，答案 3。
- **複雜度**：時間 O(mn)，額外空間 O(n)。
- **注意**：第一列全部初始化為 1；第一欄也始終只有一條路。

```java
class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1);
        for (int r = 1; r < m; r++) {
            for (int c = 1; c < n; c++) dp[c] += dp[c - 1];
        }
        return dp[n - 1];
    }
}
```

## Q55. Jump Game

[LeetCode 題目](https://leetcode.com/problems/jump-game/)

- **題意**：nums[i] 是在位置 i 的最大跳躍長度，判斷能否抵達最後一格。
- **解法**：貪心維護目前可到達的最遠位置；只要 i 可達，它能延伸的最遠處也可達。遇到 i 超出邊界就不可能跨越缺口。
- **範例**：[2,3,1,1,4]：到 index 1 時最遠可達 4，成功；[3,2,1,0,4] 被 index 3 擋住。
- **複雜度**：時間 O(n)，額外空間 O(1)。
- **注意**：原始題單放在 DP 類，但本解法使用貪心，不需要保存每一格的 DP。

```java
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }
}
```
